Privacy Policy

Effective date: November 23, 2026 · 生效日期：2026 年 11 月 23 日

This Privacy Policy explains how Anomaly Archive Studio ("the Studio", "we") handles information when it uses its private channel-management toolchain ("the Tool") with the YouTube API Services and the Instagram Platform (Meta). The Tool is operated by one individual for the Studio's own accounts only. It has no public sign-up and no other users.

本政策說明 Anomaly Archive Studio（以下稱「本工作室」）使用私人頻道管理工具（以下稱「本工具」） 串接 YouTube API 服務與 Instagram 平台（Meta）時如何處理資訊。本工具由個人經營，只用於本工作室自有帳號， 沒有公開註冊，也沒有其他使用者。

1. Third-party terms

By using the YouTube features of the Tool, the Studio is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Instagram data is also subject to Meta's Privacy Policy and the Meta Platform Terms. Publishing is performed through third-party publishing services: Zernio (primary; Privacy Policy, Terms of Service) and Upload-Post (earlier posts; Privacy Policy, Terms of Use).

使用本工具的 YouTube 功能即受 YouTube 服務條款約束；Google 的資料處理方式請見 Google 隱私權政策； Instagram 資料同時適用 Meta 隱私權政策與 Meta 平台條款。影片發布透過第三方發布服務 Zernio（主要） 與 Upload-Post（較早的貼文）進行，適用其隱私權政策與服務條款。

2. Information the Tool accesses

SourceDataPurpose
YouTube Data API (read-only) The Studio's own channel and video list; comments on the Studio's own videos. Read comments for creative feedback.
YouTube Analytics API Aggregated statistics for the Studio's own videos (views, watch time, audience retention, shares). Measure which parts of an episode keep viewers watching.
Instagram Platform (Meta) The Studio's own Instagram professional account ID and username; insights for the Studio's own Reels (views, reach, average watch time, shares, saves, skip rate); comments on the Studio's own posts. Measure performance; read feedback.
Zernio and Upload-Post (third-party publishing services) Sent by the Tool: the Studio's own finished video files, thumbnails, titles, descriptions and captions. Received: performance statistics (views, likes, shares, saves, watch time, retention) and comments for the Studio's own posts. These services hold the connection to the Studio's own YouTube channel and Instagram account. Publish the Studio's Shorts and Reels; measure their performance.

Comments may include the public username and text of people who commented on the Studio's own posts. The Tool does not collect any other personal information, does not use cookies or trackers, and this website itself does not collect any data.

留言資料可能包含在本工作室作品下留言者的公開名稱與內容。除此之外本工具不蒐集其他個人資訊， 不使用 Cookie 或追蹤器；本網站本身也不蒐集任何資料。

3. How information is used

  • Only to publish the Studio's own content and to analyze the performance of the Studio's own content.
  • Never sold, rented, used for advertising, or used to build profiles of individuals.
  • Shared with no third party except the publishing services Zernio and Upload-Post, which receive only the Studio's own videos, thumbnails and captions in order to publish them. Data the Tool reads from the YouTube API (statistics, retention, comments) is never sent to these services or anyone else.
  • Never used to access, read or post to any account other than the Studio's own.

The Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

資料只用於發布及分析本工作室自己的作品；絕不販售、出租、用於廣告或建立個人輪廓。 除發布服務 Zernio 與 Upload-Post 只接收本工作室自己的影片、縮圖與文案以進行發布之外，不分享給任何第三方； 本工具從 YouTube API 讀取的資料（統計、留存、留言）絕不傳給這些服務或任何人。 本工作室對 Google API 所取得資料的使用與傳輸，遵守 Google API 服務使用者資料政策（含 Limited Use 規範）。

4. Storage and security

  • Access tokens and API data are stored only on the Studio owner's own computer, in files that are excluded from version control and never published.
  • The Studio operates no server of its own; the Tool's only network requests go over HTTPS to the Google and Meta APIs (reading data) and to Zernio and Upload-Post (publishing and reading the Studio's own post statistics).

存取權杖與 API 資料只儲存在負責人自己的電腦上，排除於版本控制之外且從不公開； 本工作室沒有自己的伺服器，本工具只以 HTTPS 連線到 Google 與 Meta 的 API（讀取數據）， 以及 Zernio 與 Upload-Post（發布並讀取自己作品的成效）。

5. Retention

YouTube API data (statistics, retention data, comments and reports derived from them) is kept locally for no more than 30 days; the Tool automatically deletes older files each time it runs, in line with the YouTube API Services Developer Policies. Statistics about the Studio's YouTube videos received from Zernio or Upload-Post are kept for no more than 30 days in the same way. Instagram data is kept locally for up to 24 months to compare episodes, then deleted.

YouTube API 資料（統計、留存、留言及由其產生的報告）於本機保存不超過 30 天，本工具每次執行時會自動刪除較舊的檔案； 從 Zernio 或 Upload-Post 取得的 YouTube 影片統計亦同樣保存不超過 30 天；Instagram 資料於本機保存最長 24 個月以比較各集表現，之後刪除。

6. Revoking access

  • Google / YouTube: Google Account → Third-party connections (security settings page).
  • Instagram / Meta: Instagram → Settings → Website permissions → Apps and websites, or Meta Business Settings → Integrations.
  • Zernio: disconnect the YouTube or Instagram account in the Zernio dashboard, or remove Zernio's access from the Google / Instagram settings above.
  • Upload-Post: disconnect the YouTube or Instagram account in the Upload-Post dashboard (Manage users), or remove Upload-Post's access from the Google / Instagram settings above.

可隨時至 Google 帳戶的「第三方連結」、Instagram／Meta 商業設定，或 Zernio、Upload-Post 後台的帳號管理頁， 撤銷本工具及這些發布服務的存取權。

7. Data deletion

If you commented on one of the Studio's posts and want any copy of your comment removed from the Studio's local analytics files, email the address below with the post link and your username. Your data will be deleted within 30 days and you will receive a confirmation. Revoking the Tool's access (section 6) also stops all future collection.

如果你曾在本工作室作品下留言，並希望刪除本工作室本機分析檔中的留言副本， 請寄信至下方信箱並附上貼文連結與你的帳號名稱，我們將於 30 天內刪除並回信確認。

8. Children

The Studio's content is not directed to children under 13, and the Tool does not knowingly process children's information.

本工作室內容不以 13 歲以下兒童為對象，本工具亦不會刻意處理兒童資訊。
